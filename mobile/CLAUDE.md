# CLAUDE.md

Guidance for Claude Code when working in this repository.

This file and [`AGENTS.md`](AGENTS.md) say the same thing; both exist because
different tools look for different filenames. If you change one, change the
other.

## What this is

The Tuveloz mobile marketplace app: customers describe automotive work they
need, independent providers quote on it. Launch market is Montgomery County,
Maryland. React Native + Expo + TypeScript.

## Read before changing anything

1. [`PROJECT_STATUS.md`](PROJECT_STATUS.md) — what is built, what is verified,
   what is deliberately unfinished.
2. [`docs/DECISIONS.md`](docs/DECISIONS.md) — the decision log.
3. [`docs/CONTRIBUTING.md`](docs/CONTRIBUTING.md) — conventions.

## Hard rules

- **Never commit to `main`.** Branch, then open a pull request.
- **Run `npm run verify` before every commit** — typecheck, lint, format check.
  This is exactly what CI runs.
- **Never commit secrets.** Only publishable identifiers belong in
  `EXPO_PUBLIC_*`; everything there ships inside the binary and is readable by
  anyone who installs the app.
- **Do not rewrite working features** without a stated reason. If a decision in
  `docs/DECISIONS.md` looks wrong, write a new ADR that supersedes it rather
  than quietly reversing it.
- **Do not delete existing work** unless it is genuinely obsolete — and say so
  in the commit message.
- **Update `PROJECT_STATUS.md`** when a milestone lands.

## Architecture rules

Dependencies point one way: `src/app` (routes) → `src/features` → `src/lib`.
Never the reverse.

- Screens hold view state only. Logic goes in `src/features/<feature>`.
- No `supabase.from(...)` in a screen — use a repository.
- No `firebase/*` imports in a screen — use `src/lib/firebase/auth.ts`.
- No hex values or font sizes in components — use tokens and utility classes.
- Service functions return `Result<T>`; they do not throw.
- Every new table gets RLS **and** its policies in the same migration.

Full detail in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Traps already hit — do not rediscover these

- **`src/types/database.ts` uses type aliases, not interfaces.** Interfaces do
  not get implicit index signatures, so supabase-js silently infers `never` for
  every query result. It compiles. It just stops working.
- **`supabase.auth.*` throws.** supabase-js disables its own auth namespace
  when a custom `accessToken` is supplied. Identity is Firebase's job.
- **Typed routes are generated by `expo start`** into `.expo/types`. A fresh
  clone typechecks with looser `href` types until the dev server has run once.
- **`getReactNativePersistence` only exists in Firebase's React Native build.**
  `src/types/firebase-auth-react-native.d.ts` declares it so the call site
  stays typed.

## Report honestly

`PROJECT_STATUS.md` separates "verified" from "not yet verified" on purpose.
If something has not been run, say so. Do not describe untested code as
working.
