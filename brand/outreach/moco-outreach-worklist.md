# MoCo provider outreach — worklist

A copy-paste target list so sending the DMs is friction-free. The messages
themselves live in [provider-outreach-kit.md](provider-outreach-kit.md) (EN + ES).
This file is just **who to send them to, in what order, and how to not get burned.**

Goal: provider applications at https://tuveloz.com/join
Audience: independent mobile mechanics, detailers, and jump-start/roadside
operators already advertising in Montgomery County, MD.

---

## The one rule that prevents the only real problem later

The single thing that can kill this channel is getting your account **flagged as
spam** (Facebook/Nextdoor will limit or ban it). Everything below is built to
avoid that. Follow these and you never have a mess to clean up:

1. **Personalize the first line every time.** Never paste the same message twice
   in a row — reference their actual post/service/area. The templates leave a
   `[bracket]` for exactly this.
2. **Pace it.** Max ~5–8 new messages per day from one account. Slow looks human;
   a burst looks like a bot.
3. **One follow-up, ever. None after a "no."** (Already the kit's rule.)
4. **Track every send below** so the same person never gets hit twice — a double
   message is what makes you look like a spammer.

If you only remember one thing: **slow + personalized + tracked = never banned.**

---

## Daily plan (about 15 minutes)

- Pick **5 targets** from the list below (top of the list first).
- For each: open their page/post → copy the matching template → **rewrite the
  first line** to mention their actual work → send.
- Mark the row `Sent — <date>`.
- Next day, check for replies first, then send 5 more.

That's it. 5 a day = ~25 real providers reached in a week, with zero spam risk.

## Tier 2 — Search recipes to refill the list (do these when Tier 1 runs low)

Run each search, then DM the independent operators you find (same template).
These are the exact queries — copy, paste, go:

**Facebook (search bar → filter to People/Pages/Marketplace):**
- `mobile mechanic Montgomery County MD`
- `mobile mechanic Silver Spring` / `Rockville` / `Gaithersburg` / `Germantown`
- `mobile car detailing Montgomery County`
- `jump start service near me` (set location to a MoCo town)
- Marketplace → **Services** category, location set to Silver Spring/Rockville

**Nextdoor** (post as a Business, in the Services area, one MoCo neighborhood at a time):
- Browse "Recommendations" → auto/car → message people advertising services

**Craigslist** (washingtondc.craigslist.org → services → automotive, or gigs):
- Search `mobile mechanic`, `mobile detailing`, `jump start` — filter to MoCo towns

**Instagram** (search these hashtags, DM local independents):
- `#montgomerycountymd` `#silverspringmd` `#rockvillemd` `#gaithersburgmd`
  paired with `#mobilemechanic` / `#mobiledetailing`

**MoCo towns to anchor every search:** Silver Spring, Rockville, Gaithersburg,
Germantown, Bethesda, Wheaton, Takoma Park, Montgomery Village, Aspen Hill,
Olney, Kensington, Damascus.

## Tier 3 — Group posts (higher reach, higher spam-risk — do sparingly)

Post **one** short, non-salesy value post (not the DM), and only where group rules
allow business posts. Space these out — one group per day max.

- Search Facebook Groups for: `Montgomery County MD buy sell`, `Silver Spring
  community`, `Rockville / Gaithersburg community`, and local `mobile mechanic`
  / `car help` groups (e.g. Maryland mobile-mechanic groups surfaced in search).
- Read each group's pinned rules first. If self-promo is banned, don't post —
  DM active service-posters individually instead (Tier 1 behavior).

## Reply handling (so a "yes" doesn't stall)

- **Interested?** → send the link plainly: `tuveloz.com/join`. Don't oversell.
  Remind them it's free and applying now = reviewed and ready at launch.
- **"Is it live / are there jobs now?"** → be honest: not yet; applying now gets
  their review done so they're ready day one. (Never imply jobs are waiting.)
- **"No" / no reply after one follow-up** → stop. Mark it and move on.

---

## What NOT to do (the traps that create work later)

- ❌ Don't blast identical copy — instant spam flag.
- ❌ Don't buy lists or scrape emails — burns the domain's sender reputation.
- ❌ Don't promise income, job volume, or perks not on the site.
- ❌ Don't follow up more than once.
- ❌ Don't contact anyone already marked `Sent` above.
