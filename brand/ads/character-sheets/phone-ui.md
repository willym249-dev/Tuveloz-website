# TUV-UI-01 — the Tuveloz phone screen (shot 3)

Role: the one branded element inside the story. NOT AI-generated — a real
screenshot of the tuveloz.com job-post flow, composited as a clean
full-screen UI insert between shots 3 and 4 (reads better on mobile than a
tiny over-the-shoulder phone screen, per the Ad 02 spec).

## Source of truth

- Capture from the real site (job-post / service-request flow), mobile
  viewport 390×844, light mode, English. Spanish version optional later —
  same frame, second capture.
- Pre-launch phase gate: the flow shown must NOT imply a customer can book
  today. Show the request form being filled, cut before any live "submit"
  confirmation, and let the end card carry "Launching soon".

## Insert spec

- Full-screen UI card on a soft neutral background (blurred shot-3 frame at
  ~20% works), device-frame optional but consistent with brand kit
- Duration: ~2.0 s inside shot 3's slot (0:09–0:14)
- One interaction shown: request typed → send tap. One UI click SFX.
- Type stays legible at 1080×1920 crop — check the 9:16 master, not just 16:9

## What may NEVER change

- It is a REAL screenshot — never an AI mock of the UI (wrong fonts and
  hallucinated copy read as fake instantly)
- Brand lockup and colors exactly as shipped on the site
