# ventures/

Scratch space for ventures that are **not Tuveloz**. Nothing here is imported by
the Worker, referenced by `docs/README.md`, or covered by the marketplace locks,
policy hashes, or launch gates described in the root `CLAUDE.md`.

It lives in this repository only because it started in a session working out of
this checkout. Anything that survives contact with a paying customer should be
extracted to its own repository and deleted from here.
